# arduino-automated-irrigation-system
An automated irrigation system developed using Arduino to monitor soil moisture levels and control plant watering based on real-time sensor readings.

Features:
Soil Moisture Monitoring: Measures soil moisture levels using a sensor.
Automatic Watering: Activates a water pump when soil moisture falls below a predefined threshold.
Controls a water pump through a relay module.
Integrates an LCD display for system information.
Uses Arduino programming to coordinate hardware operations.
Demonstrates basic automation and embedded systems concepts.

Technologies
Arduino (C/C++)
Soil Moisture Sensor
Relay Module
Water Pump
LCD Display
Electronic Circuit Design

How It Works
1)The soil moisture sensor measures the moisture level.
2)The Arduino processes the sensor reading and compares it with a predefined threshold.
3)If the soil is too dry, the Arduino activates the relay to turn on the water pump.
4)Once the moisture level reaches the desired threshold, the pump turns off.
5)The LCD displays moisture readings and system status.

Project Purpose
Developed to explore the integration of software and hardware through a practical automation project, applying programming, circuit design, and problem-solving skills.
